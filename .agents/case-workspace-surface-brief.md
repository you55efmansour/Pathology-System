# Case workspace

Mode: Operate.

Inherit the reference application's sidebar, header, shared controls, dense tables and feature decomposition. Replace its purchasing blue with a plum and teal palette inspired by the color relationship in laboratory slide stains, without using diagnostic imagery. Keep light work surfaces suited to long desktop sessions. The case table is the primary visual object; counts are compact filters, not a dashboard of metric cards.

First viewport: slim white navigation, facility header, clear Case worklist heading and New case action, a compact workflow summary, then searchable status tabs and an accessible table. At mobile sizes navigation becomes a focus-managed drawer; forms stack and tables scroll within their own region.

Signature interaction: the case workspace keeps a connected workflow rail and a persistent patient/specimen summary as the user advances. The active step uses teal, completed steps a checkmark; review and finalization visibly change available actions. Dialogs use a brief downward settling motion, honoring reduced motion. No decorative raster imagery is needed.
